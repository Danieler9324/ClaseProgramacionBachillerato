# Mi camino en la programacion - Bachillerato

Bienvenido. En este repositorio es donde guardo las actividades y proyectos de desarrollé a lo largo de mis clases de programacion en el bachillerato. Aqui documento mi aprendizaje en lenguajes y tecnologías como **Python, MySQL, HTML, CSS, JavaScript y C#**.

## Python 
Durante el segundo y tercer semestre, aprendí desde los fundamentos a los conceptos intermedios:
* Iteraciones y condicionales.
* Conexion con base de datos mediante MySQL.
* Programación Orientada a Objetos (POO).
* Programación Orientada a Eventos (POE).

Aplique estos conocimientos en el proyecto **"Juego de la Ignorancia"**, donde utilicé librerías como `tkinter`, `pygame` y me conecté a una base de datos MySQL (mediante phpMyAdmin). Aqui fue donde di mis primeros pasos sólidos a la programación.

# MySQL
En el cuarto semestre profundicé en el diseño y estructuración de bases de datos. Mis conocimientos incluyen:
* Consultas con `JOIN` (LEFT, RIGHT, INNER).
* Subconsultas.
* Procedimientos almacenados y *triggers* (disparadores).

Aunque ya había tenido un acercamiento previo a esta tecnología, en esta etapa logré comprenderla y aplicarla a fondo.

## HTML, CSS y JavaScript
En el quinto semestre aprendí el funcionamiento de las páginas web y el comportamiento del DOM (Document Object Model). Desarrollé interfaces funcionales, entre las cuales destacan:
* Un proyecto de tienda en línea (alojado en: https://github.com/Danieler9324/TiendaProyecto (https://danieler9324.github.io/TiendaProyecto/)).
* Un portafolio básico.
* Diversos ejemplos prácticos de maquetación con HTML y CSS.

## C#
En el sexto semestre aprendí sobre la creación de aplicaciones moviles, mediante la herrmienta llamada `Xamarin`. Desarrollé juegos, los cuales son:
* Un juego del Gato para Windows
* Un juego del Gato para Android
